# Consulta de lugares de votación — Elecciones FEC UdeC 2026

## Contenido
- `index.html`: página web autónoma con identidad visual TRICEL FEC 2026–2027, fechas e información del proceso; incluye los datos de la planilla y no requiere servidor ni base de datos.

## Probar localmente
Abre `index.html` en un navegador.

## Publicar gratis con GitHub Pages
1. Crea un repositorio en GitHub (por ejemplo, `consulta-votacion-fec-udec`).
2. Sube `index.html` a la raíz del repositorio.
3. En Settings → Pages, habilita la publicación desde la rama principal (`main`) y la carpeta raíz (`/root`).
4. Espera a que GitHub Pages genere la dirección pública y compártela.

## Actualizar asignaciones
Los datos están dentro de `index.html`, en la constante `assignments`. Para actualizar la información, reemplaza esa lista con los registros nuevos y vuelve a subir el archivo.

## Importante
Esta versión es una consulta informativa basada en la planilla entregada. Antes de publicarla, confirma que las asignaciones estén vigentes y autorizadas para difusión pública. La página no pide RUT ni almacena consultas.
